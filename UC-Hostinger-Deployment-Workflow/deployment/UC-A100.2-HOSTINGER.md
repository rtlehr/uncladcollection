# UC-A100.2 Hostinger Deployment

## Before deployment

```powershell
php artisan migrate
php artisan wayfinder:generate --with-form
php artisan test --filter=AssetPresentationServiceTest
php artisan test --filter=AssetPresentationManagerTest
npm run build
git add -f public/build
```

## After deployment

```bash
cd /home/u534944418/domains/staging.uncladcollection.com/public_html

php artisan migrate --force
php artisan optimize:clear
```

Confirm:

```bash
ls -la public/storage
```

Generated marketplace images use Laravel's public disk and therefore require the
existing storage link.

Clear Hostinger's site cache once after deployment.
