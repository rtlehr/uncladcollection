# Unclad Collection Brand Language Guide

## Brand position

Unclad Collection is a curated digital asset marketplace and publishing platform serving the nudist community. Customer-facing language should feel professional, respectful, welcoming, clear, and future-ready.

## Core vocabulary

| Avoid in customer-facing UI | Preferred wording |
|---|---|
| Images (as the marketplace destination) | Marketplace |
| Image (as a product) | Asset |
| Image library | Marketplace |
| Photographer | Creator |
| Blog | Stories |
| Blog post/article (general navigation) | Story |
| My Purchases / Purchase History | My Library |
| Image Details | Asset Details |
| Image Files | Files |
| Available Content | Included Files |
| License Options | Choose Your License |
| Related Images | Related Assets |
| Browse Images | Browse Marketplace |

## Important exceptions

Use format-specific terms when technically accurate. Examples: “preview image,” “image dimensions,” “upload an image,” and “JPG image” remain correct. Admin modules explicitly marked **Legacy Images** retain image terminology because they manage the compatibility system. Database tables, PHP models, routes, and internal variable names are not renamed by UX-001.

## Voice

- Prefer direct, helpful language.
- Describe the customer outcome rather than the system implementation.
- Use “Choose your license” rather than “Select license type.”
- Use “Build your library” rather than “View purchase records.”
- Avoid exaggerated marketing claims.
- Treat nudism as normal, social, wholesome, and human.
