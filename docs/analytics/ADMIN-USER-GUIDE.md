# Marketplace Intelligence Admin Guide

## Access

Users need all of the following:

- An authenticated account
- A verified email address
- `view_admin`
- `view_reports`

## Using reports

1. Open any Marketplace Intelligence report from the shared analytics navigation.
2. Choose a reporting period or custom date range.
3. Apply report-specific filters.
4. Select a row or title to open its detail report where available.
5. Use **Export CSV** for spreadsheet analysis.
6. Use **Print** for a clean printable summary; navigation and filters are hidden automatically.

## Recommended review cadence

- Daily: Operations, failed payments, stalled orders, manual-attention queue.
- Weekly: Executive overview, assets, customers, search gaps, campaign performance.
- Monthly: Financial, license utilization, content performance, retention and trend comparisons.

## Interpreting influence metrics

Campaign, blog, and search influence metrics connect registered-user activity within the same reporting period. They help identify likely contribution but should not be described as direct attribution without a dedicated attribution model.

## Data delays

Most event reports update as events are recorded. Cached report results may remain visible for the configured cache duration, normally five minutes. New events automatically advance the analytics cache version.
