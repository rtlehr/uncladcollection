# Marketplace Writing Style

## Headings

Use short, customer-oriented headings:

- Included Files
- Choose Your License
- Specifications
- Related Assets
- My Library

## Buttons

Use an action plus a clear destination or outcome:

- Browse Marketplace
- View Asset
- Save Asset
- Download Asset
- Read Stories

## Empty states

Explain what happened and offer a next action. Example:

> Your library is empty. Browse the marketplace and choose a license to add your first asset.

## Technical wording

Use file-format terms precisely. “Image” remains appropriate when discussing an actual JPG, PNG, TIFF, preview image, dimensions, or image-specific editor control.
