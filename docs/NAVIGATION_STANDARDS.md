# Navigation Standards

## Public navigation

1. Marketplace (`/images`)
2. Stories (`/blog`)
3. About (`/public-page`)
4. Favorites (`/favorites`) when authenticated

The existing URLs remain unchanged to protect compatibility, bookmarks, and SEO. Labels describe destinations rather than implementation details.

## Member navigation

- Dashboard
- Stories
- Marketplace
- Favorites
- My Library

“My Library” is the customer-facing destination for purchased licenses and assets.

## Administration

Technical admin terminology remains explicit. **Assets** is the primary media-management module. **Legacy Images** remains visible while compatibility workflows are still required. Administrative modules such as Blog Posts, License Types, Orders, and Downloads keep their technical names.
